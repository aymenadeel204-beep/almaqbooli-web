# 🌐 دليل نشر منصة مطعم المقبولي السحابية (Web Platform & API Deployment)
### تم الإعداد بواسطة: شركة AYNEX للبرمجيات والأنظمة الذكية © 2026

---

## 1. نظرة عامة على المنصة
منصة الويب السحابية لمطعم المقبولي مبنية بتقنية **Node.js (Native - Zero Dependencies)** ومصممة كـ **Progressive Web App (PWA)** توفر:
- **واجهة لوحة تحكم ومتابعة فورية للمطعم**: تعمل على الحواسيب والهواتف الذكية عبر المتصفح.
- **محرك مزامنة سحابي (API)**: يستقبل العمليات والمبيعات والمصروفات والورديات لحظياً من برنامج نقاط البيع المكتبي (C# Desktop).
- **قاعدة بيانات خفيفة وسريعة**: ملف `cloud_db.json` مع تفريغ قاعدة البيانات الحقيقية `real_db_dump.json`.

---

## 2. ما هي الملفات التي يجب رفعها للاستضافة؟ وما الملفات التي لا يجب رفعها؟

### ✅ الملفات التي يجب رفعها (موجودة كلها داخل هذا المجلد):
1. `server.js` (محرك الخادم والـ API ومعالج طلبات الـ HTTP).
2. `package.json` (بيانات التطبيق وأمر التشغيل `npm start`).
3. `cloud_db.json` (قاعدة البيانات السحابية الحالية للطلبات والمزامنة).
4. `real_db_dump.json` (بيانات المخزون والمواد الخام الحقيقية المستخرجة من المطعم).
5. مجلد `public/` بالكامل:
   - `index.html` (واجهة لوحة التحكم).
   - `style.css` (ملف التنسيقات والتصميم).
   - `app.js` (منطق الواجهة والتفاعل اللحظي).
   - `manifest.json` و `sw.js` (تفعيل تطبيق PWA للتثبيت على الهواتف).
   - مجلد `images/` (صور الوجبات والشعارات).
6. `Procfile` و `render.yaml` و `Dockerfile` (ملفات توجيه خوادم الاستضافة السحابية).

### ❌ الملفات التي لا يجب رفعها:
- ❌ ملف قاعدة البيانات المحلية للعميل `restaurant.db` (خاصة بجهاز الكاشير فقط).
- ❌ ملفات الكود المصدري لبرنامج C# (`.cs`, `.csproj`, `.sln`, `.pdb`).
- ❌ مفاتيح سرية مكشوفة أو كلمات مرور شخصية.
- ❌ أدوات التطوير المحلية ومجلدات `.git` أو `node_modules`.

## 3. خيارات الاستضافة خطوة بخطوة

### الخيار الأول: الاستضافة السحابية المجانية 100% عبر [Render.com] (موصى بها)
> **المميزات**: مجانية بالكامل، لا تتطلب بطاقة بنكية، شهادة أمان SSL تلقائية (`https://`).

#### خطوات النشر:
1. ادخل إلى موقع [Render.com](https://render.com) وأنشئ حساباً مجانياً (باستخدام بريدك الإلكتروني أو GitHub).
2. أنشئ مستودعاً جديداً (Private أو Public) على GitHub باسم `almaqbooli-cloud` وارفع إليه محتويات هذا المجلد.
3. في لوحة تحكم Render:
   - اضغط على زر **New +** ثم اختر **Web Service**.
   - اختر مستودعك من GitHub.
4. اضبط الإعدادات كالتالي:
   - **Name**: `almaqbooli-pos` (أو أي اسم تفضله).
   - **Region**: `Frankfurt (EU)` أو أقرب منطقة لك.
   - **Environment**: `Node`.
   - **Build Command**: `npm install` (أو اتركه فارغاً لأنه لا يحتاج حزم خارجية).
   - **Start Command**: `node server.js`
   - **Plan Type**: `Free`.
5. في قسم **Environment Variables** (المتغيرات):
   - أضف المتغير: `PORT` = `5173`
6. اضغط على **Deploy Web Service**.
7. بعد انتهاء النشر (خلال دقيقة إلى دقيقتين)، ستحصل على رابط حي ومؤمن مثل:
   `https://almaqbooli-pos.onrender.com`

---

### الخيار الثاني: الاستضافة السحابية عبر [Railway.app]
1. ادخل إلى [Railway.app](https://railway.app).
2. اضغط **New Project** -> **Deploy from GitHub repo**.
3. سيتعرف Railway تلقائياً على ملف `package.json` و `Procfile`.
4. اضغط على إعدادات المشروع (Settings) -> **Generate Domain** لتحصل على رابط فوري مجاني.

---

### الخيار الثالث: خادم VPS خاص (Ubuntu / Linux)
إذا كان العميل يمتلك خادماً خاصاً (DigitalOcean / Hetzner / AWS Lightsail):
1. انسخ ملفات المجلد إلى الخادم في المسار: `/var/www/almaqbooli`.
2. ثبّت Node.js:
   ```bash
   sudo apt update && sudo apt install -y nodejs npm
   ```
3. ثبّت مدير العمليات PM2 لتشغيل المنصة في الخلفية بشكل دائم:
   ```bash
   sudo npm install -g pm2
   cd /var/www/almaqbooli
   pm2 start server.js --name "almaqbooli"
   pm2 startup
   pm2 save
   ```
4. اربط المنصة مع Nginx كـ Reverse Proxy على المنفذ `5173`.

---

### الخيار الرابع: تشغيل فوري عبر نفق سحابي آمن (Cloudflare Tunnel) بدون رفع
إذا أردت تشغيل المنصة من جهاز الكاشير أو جهازك مباشرة وجعلها متاحة على الإنترنت مجاناً دون استضافة خارجية:
1. افتح نافذة الأوامر وشغل خادم المنصة محلياً على المنفذ `5173`.
2. شغّل Cloudflare Tunnel المرفق في المشروع:
   ```cmd
   cloudflared_win.exe tunnel --url http://localhost:5173
   ```
3. سيعطيك Cloudflare رابطاً سحابياً مؤمناً ينتهي بـ `.trycloudflare.com`، يعمل فوراً من أي هاتف في العالم.

## 4. اختبار المنصة بعد النشر
1. **فتح الرابط**: افتح الرابط في المتصفح وتأكد من ظهور شعار مطعم المقبولي وواجهة النظام الفاخرة.
2. **تسجيل الدخول**:
   - المستخدم: `المقبولي`
   - كلمة المرور: `54321`
3. **فحص الـ API**: افتح في المتصفح الرابط: `https://your-domain.com/api/auth/me` للتأكد من استجابة خادم الـ API.
4. **تثبيت تطبيق PWA**: اضغط على أيقونة التثبيت (Install App) في شريط المتصفح لتثبيت المنصة كأيقونة مستقلة على سطح المكتب أو شاشة الهاتف الرئيسية.
